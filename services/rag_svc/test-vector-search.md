# Vertex AI Vector Search

Vertex AI Vector Search (formerly Matching Engine) is a specialized service designed for vector embeddings. It simplifies implementation by handling vector similarity search operations natively in the cloud service rather than requiring complex application code.

## Key Features

- High-performance vector similarity search
- Scalable to billions of vectors
- Low latency retrieval
- Integration with other Google Cloud services

## Use Cases

Vector Search is ideal for RAG (Retrieval Augmented Generation) applications where finding relevant context quickly is essential for generating accurate responses.
